# CW Water Budget Analysis 2025 (Power BI)

## 📌 Project Overview
This project analyzes the 2025 global sales and budget projections for CW Water.
The goal is to support budgeting and management decision-making through clear and interactive Power BI dashboards.

## 📊 Key Analysis
- Monthly sales volume trends
- Revenue breakdown by region and channel
- SKU-level contribution analysis
- Seasonality patterns across 2025

## 🛠 Tools Used
- Power BI
- Microsoft Excel
- Data modeling & DAX
- Data visualization

## 📂 Project Files
- Power BI dashboard (.pbix)
- Source data (Excel)
- Dashboard screenshots
